# Rona Codex Marketplace

[Rona](https://rona.so) 의 Codex CLI 플러그인 마켓플레이스.

## 포함된 플러그인

- **rona-review** — Rona 맞춤 스킬 사용 후 후기 작성 + 자동 전송

## 학습자 설치

```bash
codex plugin marketplace add chat-prompt/rona-codex-marketplace
```

설치 후 Codex 안에서 `$rona-review:rona-review` 호출.

## Rona 본체

- 웹: https://rona.so
- 본 레포는 Codex 호환용 entrypoint이고, 실습 본문은 `rona.so/skill/api/install/<token>` 에서 동적 제공.
